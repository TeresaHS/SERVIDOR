CONEXION.PHP

Aquí guardo la conexión a la base de datos. Ahora uso PDO.

En el constructor pongo PDO::ATTR_ERRMODE a ERRMODE_EXCEPTION para que, si hay un error de SQL, me lance una excepción en vez de un warning. Así sé cuándo algo falla.

Los tres métodos de transacción (empezar, confirmar, deshacer) los uso en guardarHorario() para que, si algo falla, no se quede el horario a medias. Con PDO son beginTransaction(), commit() y rollBack().

ejecutar($sql) es la base de todo: intenta ejecutar la consulta y me devuelve un array con:
- ok: true o false
- error: el mensaje de error si falla
- codigo: el código de error de MySQL (1062, 1451, etc.), que saco de $e->errorInfo[1]
- resultado: el objeto que devuelve query()

Así, en los controladores, puedo hacer if(!$res['ok']) y saber qué ha pasado sin usar try/catch en cada sitio.

fetchTodo($sql) me devuelve un array de filas (para SELECT de muchos). Uso fetch(PDO::FETCH_ASSOC).

fetchUno($sql) me devuelve una sola fila (para SELECT de uno). Como PDO no tiene num_rows, hago fetch(PDO::FETCH_ASSOC) y compruebo si devuelve false.

existe($sql) me devuelve true o false. Lo uso cuando solo me interesa saber si hay al menos una fila (por ejemplo, en tieneHorario() y estaEnHorario()). Así no repito el fetch en los modelos.

Así no repito el while(fetch) ni el fetch suelto en todos los modelos.
